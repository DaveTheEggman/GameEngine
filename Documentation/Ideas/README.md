# Ideas

Ideation documents: directions under EVALUATION, not ready for planning or a
build spec. Nothing in this folder is committed work.

The contract:

- A doc here may argue for something and still conclude "do nothing". That is a
  valid outcome, not a failed doc.
- Agents must NOT build from these documents or treat their contents as
  decisions. If a memory or plan references one, it references an open question.
- Graduation path: Ideas -> user decision -> Documentation/Specs (a build spec
  with rulings) -> Documentation/Plans (scheduling). Only the user moves a doc
  out of this folder's status.
- Keep the evaluation trail in-file (dated sections per reviewer), the same way
  Specs carry rulings - so the eventual decision shows its reasoning.
