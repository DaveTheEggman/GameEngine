- Builder/product schema change => Version() bump in the SAME commit.
- Serialized-identity renames => legacy-name fallback + test, same commit.
- Bulk data => binary sidecar stream, never inline in text envelopes.
- Pipeline targets (and their tests) stay UI-free.
- New third-party archives need distinct archive names (case-insensitive
  platforms).
- -j4 build cap; one target per cmake --build; never rm -rf Bin/.
